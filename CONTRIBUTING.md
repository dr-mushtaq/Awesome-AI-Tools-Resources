# Contributing to Awesome AI Tools & Resources

Thanks for your interest in contributing to this repository. We welcome suggestions, improvements, and new tool recommendations that help make this list more useful for the community.

If you find this project helpful, please consider starring the repository to support it.

## Ways to Contribute

You can help in several ways:

- Add a missing AI tool or resource
- Improve the description of an existing tool
- Suggest a better category for a tool
- Fix formatting or broken links
- Share feedback about the repository structure and usefulness
- Open an issue for a tool that should be added or corrected

## Before You Contribute

Please make sure your suggestion is:

- Relevant to AI tools/resources
- Useful to the community
- Accurate and up to date
- Clearly categorized

We prefer quality over quantity.

## How to Add a New Tool

1. Fork this repository
2. Open the README.md file
3. Find the appropriate category section
4. Add the tool in the correct table/list
5. Keep entries consistent in formatting
6. Submit a Pull Request with a clear title

### Suggested Tool Entry Format

Use this structure when adding a new tool:

| Tool | Description | Tags |
|------|-------------|------|
| [Tool Name](https://example.com) | Short description of what the tool does | Free, Web, Chatbot |

If the repo uses a particular category style, follow that existing formatting as closely as possible.

### Minimum Information to Include

For each tool, include:

- Tool Name
- Official link
- Short description (about 15–20 words)
- Relevant tags, such as:
  - Free
  - Paid
  - Web
  - Chatbot
  - Open Source
  - Video
  - Writing
  - Research
  - PDF
  - Design
  - Coding
  - etc.
